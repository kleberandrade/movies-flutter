# Tutorial media

`medium-cover.png` is an editorial illustration generated with the built-in image-generation tool for the project's own Medium lesson. It is not a screenshot or a depiction of authenticated TMDB data. Final exported dimensions: 1672 × 941 pixels. Actual UI screenshots are in `../screenshots/` and were refreshed from the current compiled Web demo.

## Generation prompt

Use case: illustration-story. Asset type: editorial cover for a Portuguese programming tutorial on Medium, wide landscape composition around 16:9. Create a polished restrained illustration about building a movie catalog application with Flutter and a web API. Dark midnight navy background, warm cream typography, muted teal and amber details. Abstract cinema frames, a film strip and subtle code-bracket symbols, elegant geometric depth and generous negative space. Exact large readable title: "Filmes com Flutter". Exact small subtitle: "Da API à interface, com testes". The title and composition should survive a centered mobile crop. No actual film posters, actors, company logos, device mockups, fake screenshots, version numbers, watermarks or extra words. This is a conceptual editorial illustration, not a screenshot of an application.

## Final targeted edit prompt

Remove only the blue Flutter emblem at the top center, replacing it with matching empty midnight navy background. Keep the title, subtitle, composition, typography, all other illustration objects, color palette, dimensions and lighting unchanged. The result must contain no company logos. Preserve text verbatim: Filmes com Flutter / Da API à interface, com testes.
